PENJAMINAN KUALITI SKSA - NEON v3.3 SENARAI SEMAK DASHBOARD

BAHARU DI DASHBOARD ADMIN
- Senarai semua guru aktif.
- Kira jumlah instrumen yang ditugaskan kepada setiap guru.
- Status SELESAI hanya apabila SEMUA instrumen guru berstatus SUBMITTED.
- Jika satu atau lebih belum hantar: BELUM SELESAI.
- Jika tiada tugasan: TIADA TUGASAN.
- Papar kemajuan contoh 2/3, 1/1.
- Susunan: BELUM SELESAI dahulu, kemudian TIADA TUGASAN, kemudian SELESAI.
- Carian nama + penapis status.
- Klik nama/baris atau butang Lihat untuk buka detail instrumen guru.
- Detail tunjuk status setiap instrumen: SELESAI / DRAF / BELUM MULA.
- Admin boleh Muat Turun PDF terus bagi instrumen yang telah SUBMITTED.
